# DestinyOne Approved Design Lock

Status: Locked on 2026-07-24 at the owner's request.

Do not change the approved DestinyOne visual direction without explicit owner approval.

## Approved palette

- Canvas: `#F8F3ED` ivory
- Blush panels: `#F2E4E5`, `#E9D2D6`, `#F8EDEA`
- Primary action / active state: `#A80C36` wine red
- Deep wine: `#740726`
- Supporting red: `#B30D3C`, `#D65A78`
- Gold accent: `#B98A22`
- Main text: `#27171B` espresso
- Muted text: `#75656A`
- Borders: `#E7D5CF`

## UI direction

- Light ivory and blush are the dominant surfaces.
- Wine red is reserved for actions, selected states, small badges, and high-priority moments.
- Gold is an accent only, never a dominant background.
- Keep the existing DestinyOne icon system unchanged.
- Keep card contrast readable; never put dark text on dark wine surfaces.
- Preserve responsive cards, readable typography, and visible scroll space above fixed navigation.

Any design change needs owner approval before implementation.
